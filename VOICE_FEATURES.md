# 🎤 Voice Interaction Features

JaySim now supports **real-time voice conversations** with AI clients!

## 🎯 Features

### 1. **Voice Input (Speech-to-Text)**
- Click the 🎤 **"Speak"** button to start talking
- Your speech is converted to text automatically
- Works in Chrome, Edge, and other modern browsers

### 2. **Voice Output (Text-to-Speech)**
- AI client **speaks** responses automatically
- Natural voice synthesis
- Toggle on/off with 🔊 button

### 3. **Auto-Listen Mode**
- Enable 🔄 **Auto-Listen** for hands-free conversation
- AI speaks → Automatically starts listening for your response
- Creates a natural back-and-forth conversation flow

### 4. **Visual Indicators**
- 🗣️ **"Client Speaking..."** - AI is talking
- 🎤 **"Listening..."** - Microphone is active
- Real-time status updates

## 🚀 How to Use

### Quick Start:
1. **Start a simulation** as usual
2. **Click 🎤 Speak** button
3. **Talk naturally** (browser will transcribe)
4. **AI responds with voice** automatically
5. **Continue the conversation!**

### Recommended Settings:
- **Voice On** (🔊) - Hear AI responses
- **Auto-Listen On** (🔄) - Hands-free mode
- Creates the most realistic call experience!

## 🎮 Controls

| Button | Function |
|--------|----------|
| 🎤 **Speak** | Start voice input |
| ⏹️ **Stop** | Stop listening |
| 🔊 **Voice On/Off** | Toggle AI voice output |
| 🔄 **Auto-Listen** | Auto-listen after AI speaks |
| **Type** | You can still type if preferred |

## 💡 Usage Modes

### Mode 1: Manual (Click to Speak)
1. Click 🎤 Speak
2. Say your response
3. AI responds with voice
4. Repeat

### Mode 2: Auto-Listen (Hands-Free)
1. Enable 🔄 Auto-Listen
2. Click 🎤 Speak once
3. Conversation flows automatically:
   - You speak → AI responds → Auto-listens → You speak → ...

### Mode 3: Hybrid (Voice + Text)
- Use 🎤 for speaking
- Type when needed
- Best of both worlds!

## 🔧 Technical Details

- **Speech Recognition:** Browser Web Speech API
- **Text-to-Speech:** Browser SpeechSynthesis API
- **No additional setup required**
- **Works offline** (once page loaded)
- **No audio recording stored**
